# Документация курсового проекта

Структура документации соответствует этапам выполнения курсового проекта:

- `00-initiation/` — инициация, бизнес-анализ, IDEF0, BUC, глоссарий, стейкхолдеры, SWOT и ROI.
- `01-requirements/` — функциональные и нефункциональные требования, Use Case, спецификации и трассировка.
- `02-architecture/` — PCMEF, ADR, интерфейсы и анализ зависимостей.
- `03-database/` — ER-модель, DDL и стратегия ORM.
- `04-design/` — детальное проектирование, классы, Use Case и диаграммы последовательности.
- `05-implementation/` — реализация, тестирование и итоговые результаты.
- `06-refactoring/` — рефакторинг и контроль качества.
- `07-management/` — WBS, Gantt, COCOMO, план, чек-лист и матрица соответствия методическим требованиям.
- `08-explanatory-note/` — финальная пояснительная записка.
- `images/` — диаграммы и скриншоты, используемые в проектной документации.

Mermaid-файлы (`*.mmd`) можно просматривать непосредственно в GitHub или в редакторах с поддержкой Mermaid.
