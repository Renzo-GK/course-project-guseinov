# SWOT-анализ

| Сильные стороны | Слабые стороны |
|---|---|
| Автоматическая проверка конфликтов | Зависимость от серверной БД |
| Централизованный каталог ресурсов | MVP пока не включает уведомления |
| Роли и административный контроль | Ограниченный отчётный контур |
| Docker и REST API | Нет внешней интеграции календарей |

| Возможности | Угрозы |
|---|---|
| Интеграция с Outlook/Google Calendar | Ошибки конфигурации инфраструктуры |
| Уведомления пользователям | Нагрузка при росте числа бронирований |
| Мобильный клиент | Несанкционированный доступ |
| Расширенная аналитика | Потеря данных при некорректном резервном копировании |
