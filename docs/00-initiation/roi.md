# Экономическое обоснование (ROI)

## Подход

Для учебного проекта используется сценарная оценка. До автоматизации сотрудник тратит часть рабочего времени на поиск свободной комнаты, переписку и устранение конфликтов. После внедрения значительная часть этих действий выполняется автоматически.

Пусть:
- `T0` — средние трудозатраты на ручное бронирование за месяц;
- `T1` — трудозатраты после автоматизации;
- `C` — стоимость разработки и внедрения.

Тогда условный эффект:
`E = T0 - T1`.

Годовой ROI в учебной модели:
`ROI = (12 × E - C) / C × 100%`.

Фактические числовые значения должны быть рассчитаны после согласования учебных допущений; в отчёте нельзя выдавать оценочные значения за фактические данные предприятия.
