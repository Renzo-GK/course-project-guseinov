# IDEF0 A-0. Управление бронированием переговорных комнат

## Контекст

**Входы:** запрос на поиск комнаты, параметры встречи, данные пользователя, сведения о ресурсах офиса.

**Управление:** правила бронирования, роли доступа, расписание рабочих пространств, политика отмены.

**Механизмы:** веб-клиент React, backend Spring Boot, PostgreSQL, Docker, Spring Security.

**Выходы:** созданное/отменённое бронирование, сведения о доступности, статистика использования ресурсов.

## Декомпозиция

A1 — управление пользователями и ролями.

A2 — управление каталогом рабочих пространств.

A3 — проверка доступности.

A4 — создание и отмена бронирования.

A5 — административный контроль и отчётность.
