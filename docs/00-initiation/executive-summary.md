# Исполнительное резюме

## Тема
Разработка веб-сервиса для бронирования переговорных комнат и управления рабочими пространствами.

## Цель
Создать веб-сервис, позволяющий сотрудникам находить подходящие переговорные комнаты, просматривать их параметры и бронировать свободные временные интервалы, а администраторам — управлять ресурсами и контролировать использование помещений.

## Пользователи
- сотрудник;
- администратор.

## Ключевая бизнес-ценность
Сервис сокращает ручные действия при согласовании переговорных, уменьшает количество конфликтующих бронирований и предоставляет единое пространство для управления рабочими ресурсами.

## MVP
Авторизация, каталог комнат, карточка комнаты, бронирование, контроль пересечений, личные бронирования, административное управление и REST API.
