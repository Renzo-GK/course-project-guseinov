# Расширенный глоссарий

1. Переговорная комната — помещение для встречи.
2. Рабочее пространство — управляемый ресурс офиса.
3. Бронирование — резервирование ресурса на интервал.
4. Пользователь — сотрудник сервиса.
5. Администратор — пользователь с расширенными правами.
6. Временной интервал — начало и конец бронирования.
7. Доступность — возможность резервирования ресурса.
8. Конфликт — пересечение активных интервалов.
9. Оборудование — техническое оснащение комнаты.
10. Вместимость — максимальное число участников.
11. Роль — набор разрешений.
12. Аутентификация — проверка учетных данных.
13. Авторизация — проверка прав.
14. JWT — токен доступа к API.
15. REST API — интерфейс взаимодействия клиента и сервера.
16. Workspace — единица рабочего пространства.
17. Building — здание размещения ресурса.
18. Notification — уведомление пользователя.
19. AuditLog — запись аудита административного действия.
20. Data Mapper — преобразователь Entity в DTO и обратно.
21. Identity Map — механизм уникальности объектов в persistence context.
22. Lazy Load — отложенная загрузка связанных сущностей.
23. ORM — объектно-реляционное отображение.
24. Статистика — агрегированные показатели использования ресурсов.
