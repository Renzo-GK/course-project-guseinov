# Требования

## Функциональные
FR-01. Система должна выполнять аутентификацию пользователя.
FR-02. Система должна поддерживать роли USER и ADMIN.
FR-03. Пользователь должен видеть список переговорных комнат.
FR-04. Пользователь должен видеть параметры комнаты.
FR-05. Пользователь должен выбирать дату и временной интервал.
FR-06. Система должна запрещать пересекающиеся бронирования одной комнаты.
FR-07. Пользователь должен видеть свои бронирования.
FR-08. Пользователь должен иметь возможность отменить собственное бронирование.
FR-09. Администратор должен управлять комнатами.
FR-10. Система должна предоставлять REST API.
FR-11. Система должна выполнять валидацию входных данных.
FR-12. Система должна предоставлять сведения для статистики.

## Нефункциональные
NFR-01. Backend: Java 17+ и Spring Boot.
NFR-02. СУБД: PostgreSQL.
NFR-03. Клиентская часть: HTML/CSS/JS; в реализации используется React + TypeScript.
NFR-04. Пароли должны храниться в хэшированном виде BCrypt.
NFR-05. SQL должен выполняться через ORM/repository-слой.
NFR-06. Интерфейс должен быть адаптивным.
NFR-07. Проект должен запускаться через Docker Compose.
NFR-08. Ключевая бизнес-логика должна покрываться автоматическими тестами.
