# Финальный план перед сдачей

1. Завершить runtime-проверку JWT после успешного `docker compose build`.
2. Зафиксировать JaCoCo screenshot / HTML report.
3. Добавить 1–2 обоснованных GoF-паттерна.
4. Подготовить WAR/Tomcat deployment instructions.
5. Рассчитать COCOMO и оформить Gantt.
6. Сформировать пользовательское руководство и руководство администратора.
7. Собрать пояснительную записку по структуре методички.
8. Подготовить приложения: листинги, скриншоты, тестовые результаты.
9. Подготовить презентацию и 5–7 минутный текст защиты.
