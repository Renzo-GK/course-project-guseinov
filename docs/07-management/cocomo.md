# Оценка трудозатрат по COCOMO — учебная модель

Для отчёта рекомендуется использовать упрощённый Basic COCOMO:

`E = a × KLOC^b`

`D = c × E^d`

где KLOC — оценка числа тысяч строк кода, E — трудозатраты в человеко-месяцах, D — длительность проекта.

Поскольку фактическая сдача не требует производственного бюджета предприятия, численные параметры должны быть явно обозначены как **учебные допущения**, а KLOC следует считать по финальному Git-репозиторию перед сдачей.
