# Финальный протокол тестирования

## 1. Unit-тесты

Команда:
```bash
mvn test
```

Результат должен включать:
- `BookingServiceTest` — базовые проверки интервала и пересечений;
- `BookingServiceExtendedTest` — создание, отмена и проверка владельца;
- `RoomServiceTest` — создание и изменение комнаты.

## 2. Отчёт покрытия

После выполнения `mvn test` формируется:
`backend/target/site/jacoco/index.html`.

В пояснительной записке следует указывать фактический процент только после чтения этого отчёта.

## 3. Ручные системные сценарии

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| ST-01 | Вход обычного пользователя | Открывается пользовательский интерфейс |
| ST-02 | Вход администратора | Появляется раздел администрирования |
| ST-03 | Просмотр комнат | Отображаются комнаты и параметры |
| ST-04 | Поиск комнаты | Список фильтруется без перезагрузки страницы |
| ST-05 | Фильтр вместимости | Остаются комнаты с достаточной вместимостью |
| ST-06 | Просмотр занятости | Для выбранной даты отображаются активные интервалы |
| ST-07 | Создание бронирования | Создаётся ACTIVE-бронирование |
| ST-08 | Конфликт интервалов | Бронирование отклоняется |
| ST-09 | Отмена собственной брони | Статус меняется на CANCELLED |
| ST-10 | Попытка отмены чужой брони | Операция отклоняется |
| ST-11 | CRUD комнаты администратором | Создание, изменение и удаление контролируются ролью ADMIN |
| ST-12 | Swagger UI | API доступен для просмотра и проверки |

## 4. Smoke-тест развёртывания

```bash
docker compose up --build
```

Проверить:
- `http://localhost:5173` — frontend;
- `http://localhost:8080/swagger-ui.html` — REST API;
- подключение backend к PostgreSQL;
- наличие демо-данных.


## Порог JaCoCo

Maven build настроен так, чтобы сборка завершалась ошибкой при покрытии инструкций ниже **40%**. Это технически фиксирует требование методических материалов в CI/local build.

## Автоматический контроль

В `pom.xml` добавлен JaCoCo `check` с минимальным покрытием инструкций 40%. Таким образом, локальная сборка и CI не позволяют незаметно принять версию ниже установленного порога.
