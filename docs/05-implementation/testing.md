# Тестирование

На стартовом этапе реализованы unit-тесты бизнес-правила бронирования:
- отклонение пересекающегося интервала;
- отклонение некорректного интервала.

Команда запуска:
```bash
mvn test
```

JaCoCo подключён к Maven для формирования отчёта покрытия. По мере расширения функциональности тестовый набор должен быть доведён до требований методических материалов.
