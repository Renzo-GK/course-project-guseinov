# Финальная функциональная версия

В версии 1.0 реализованы:
- регистрация пользователя;
- аутентификация и роли;
- REST API;
- каталог и поиск переговорных;
- фильтрация по минимальной вместимости;
- создание и отмена бронирований;
- контроль пересечения активных интервалов;
- календарь занятости выбранной комнаты по дате;
- административный CRUD комнат;
- административная статистика;
- OpenAPI/Swagger;
- Data Mapper для представления комнаты;
- JPA Persistence Context как Identity Map;
- контролируемые LAZY-связи Booking с предварительной загрузкой через EntityGraph.
