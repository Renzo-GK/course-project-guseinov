# Административный контур и тестирование

## Административные функции
- просмотр количества комнат;
- просмотр количества пользователей;
- просмотр активных и отменённых бронирований;
- просмотр последних бронирований;
- добавление переговорной комнаты;
- получение полного списка бронирований через REST API.

## Тестовое покрытие бизнес-логики
Добавлены unit-тесты для:
- создания бронирования;
- запрета пересечения;
- проверки корректности интервала;
- отмены бронирования;
- запрета отмены чужого бронирования;
- создания комнаты;
- изменения комнаты.

Для проекта подключён JaCoCo. Итоговый процент покрытия фиксируется после выполнения `mvn test` в целевой среде.
