# ADR-001. Выбор технологического стека

## Решение
Java 21 + Spring Boot + PostgreSQL + React/TypeScript + Docker.

## Причины
1. Стек соответствует рекомендуемой web-траектории методических материалов.
2. Spring предоставляет готовые средства REST, security, transaction management и ORM.
3. PostgreSQL подходит для транзакционных данных бронирований.
4. React позволяет реализовать динамический адаптивный интерфейс.
5. Docker упрощает воспроизводимость демонстрационной среды.
