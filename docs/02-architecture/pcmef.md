# Архитектура PCMEF

Направление зависимостей:

`Presentation → Control → Mediator → Entity → Foundation`

- **Presentation** — REST-контроллеры и взаимодействие с HTTP.
- **Control** — DTO, валидация и конфигурация контроля доступа.
- **Mediator** — бизнес-операции и транзакционные сценарии.
- **Entity** — доменные сущности.
- **Foundation** — репозитории и инфраструктура хранения.

Основной принцип: бизнес-правила не должны быть размещены в UI, а доступ к БД выполняется через Foundation.
