# Анализ зависимостей PCMEF

## Целевое направление

`Presentation → Control → Mediator → Entity → Foundation`

## Правила

- Presentation не обращается напрямую к репозиториям.
- Control отвечает за DTO, валидацию и контроль доступа.
- Mediator реализует бизнес-правила и транзакции.
- Entity хранит состояние предметной области.
- Foundation содержит Spring Data repositories и инфраструктуру хранения.

## Вывод

Архитектурная модель проекта документирована через диаграмму PCMEF, спецификацию интерфейсов и отдельный анализ зависимостей. Проверка кода выполняется на уровне package structure и code review перед сдачей.
