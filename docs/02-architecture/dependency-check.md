# Проверка зависимостей PCMEF

Ожидаемое направление: `P → C → M → E → F`.

- Presentation использует DTO/сервисы Mediator через Control-контракты.
- Mediator содержит транзакции и бизнес-правила.
- Entity не зависит от Presentation.
- Foundation реализует доступ к данным.
- Entity и Foundation не импортируют UI-компоненты.

Для финальной защиты архитектурное правило проверяется ревью пакетов и статическим анализом.
