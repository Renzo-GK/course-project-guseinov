# ADR-003. PostgreSQL

## Решение
Использовать PostgreSQL как транзакционную реляционную СУБД.

## Обоснование
Модель предметной области содержит связи «пользователь — бронирование — комната», ограничения целостности и запросы по временным интервалам. Реляционная модель подходит для этих операций, а индексация `room_id/start_at/end_at` поддерживает проверку расписания.
