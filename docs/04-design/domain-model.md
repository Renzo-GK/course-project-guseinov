# Доменная модель

## User
Идентифицирует сотрудника и содержит учётные данные и роль.

## MeetingRoom
Описывает переговорную комнату: название, вместимость, расположение и оборудование.

## Booking
Связывает пользователя и переговорную с временным интервалом и статусом.

## Основные ограничения
1. `startAt < endAt`.
2. Для одной комнаты активные интервалы не должны пересекаться.
3. Пользователь может отменить собственное активное бронирование.
4. Администратор может выполнять операции управления ресурсами.
