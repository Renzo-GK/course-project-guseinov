# Статический анализ

Перед сдачей рекомендуется выполнить один из стандартных анализаторов Java-кода (например, Checkstyle, SpotBugs или SonarQube) и зафиксировать критические замечания в таблице исправлений.

Формат фиксации:

| Инструмент | Проблема | Приоритет | Исправление |
|---|---|---|---|
| Анализатор | Длинный метод | Medium | Разбиение по ответственности |
| Анализатор | Повторяющийся код | Low | Выделение Mapper/Service |
| Анализатор | Необработанное исключение | High | Глобальный handler |
