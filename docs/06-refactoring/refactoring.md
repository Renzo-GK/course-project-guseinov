# Рефакторинг

Запланированные меры:
1. Выделение DTO из JPA-сущностей для REST-контрактов.
2. Выделение Data Mapper для преобразования Entity ↔ DTO.
3. Использование Identity Map через persistence context JPA.
4. Контроль Lazy Load для связей Booking → User/Room.
5. Оптимизация запросов расписания и индексация времени бронирований.
6. Проверка архитектурных зависимостей PCMEF.
